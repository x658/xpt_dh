Building a modern, internationalized website from scratch takes significant time. You need to configure routing, styles, internationalization, SEO metadata, and analytics.

**Next.js Starter** is a minimal, high-performance multilingual Next.js 16 starter template engineered for shipping content sites, developer toolboxes, and landing pages in minutes.

---

## Core Features

### 🌐 Native Multilingual i18n
Powered by `next-intl`:
* **Tri-lingual Ready**: English, Chinese, and Japanese out-of-the-box.
* **Automatic Route Switching**: Clean sub-paths (`/`, `/zh`, `/ja`).
* **SEO Metadata**: Automatic alternate hreflang and canonical headers.

### 📝 MDX Blog Engine
* **Frontmatter Parsing**: Title, description, tags, publication dates, and visibility controls.
* **Syntax Highlighting**: Pre-configured code blocks and callouts.
* **Dynamic Sitemap**: Every new markdown file is automatically added to `sitemap.xml`.

### ⚡ Clean Tailwind CSS & Dark Mode
* Beautiful responsive layout with zero UI clutter.
* Seamless system / dark mode switching via `next-themes`.

## Quick Start in 3 Minutes

```bash
# 1. Clone the repository
git clone https://github.com/x658/xpt_dh.git my-site
cd my-site

# 2. Install dependencies
pnpm install

# 3. Start development server
pnpm dev
```

Visit `http://localhost:3000` to preview your multilingual site locally.
