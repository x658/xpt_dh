For commercial web applications and indie software ventures, organic discovery and user retention hinge directly upon Search Engine Optimization (SEO) and Core Web Vitals (CWV). Modern search algorithms directly incorporate Largest Contentful Paint (LCP), Interaction to Next Paint (INP), and Cumulative Layout Shift (CLS) into ranking criteria.

Leveraging Next.js 16's App Router architecture alongside React Server Components (RSC) enables developers to achieve near-perfect 100/100 Google Lighthouse scores while maintaining rich interactivity.

## 1. App Router Metadata Architecture

Next.js replaces legacy `next/head` implementations with fully typed static and dynamic metadata APIs.

### Multilingual Canonical Alternates

In `app/[locale]/blog/[slug]/page.tsx`:

```typescript
import { Metadata } from "next";

export async function generateMetadata({
  params,
}: {
  params: Promise<{ locale: string; slug: string }>;
}): Promise<Metadata> {
  const { locale, slug } = await params;
  const post = await getPostBySlug(slug, locale);

  if (!post) return {};

  const siteUrl = "https://xptdev.com";
  const canonicalUrl = `${siteUrl}/${locale}/blog/${slug}`;

  return {
    title: `${post.title} | XPT Dev`,
    description: post.description,
    alternates: {
      canonical: canonicalUrl,
      languages: {
        en: `${siteUrl}/en/blog/${slug}`,
        zh: `${siteUrl}/zh/blog/${slug}`,
        ja: `${siteUrl}/ja/blog/${slug}`,
        "x-default": `${siteUrl}/en/blog/${slug}`,
      },
    },
    openGraph: {
      title: post.title,
      description: post.description,
      url: canonicalUrl,
      siteName: "XPT Dev",
      type: "article",
      images: [
        {
          url: `${siteUrl}/api/og?title=${encodeURIComponent(post.title)}`,
          width: 1200,
          height: 630,
        },
      ],
    },
    twitter: {
      card: "summary_large_image",
      title: post.title,
      description: post.description,
    },
  };
}
```

## 2. Dynamic OpenGraph Generation via `@vercel/og`

Social sharing CTR relies heavily on polished visual presentation. Generate dynamic social cards on the edge via Satori:

```tsx
// app/api/og/route.tsx
import { ImageResponse } from "next/og";
import { NextRequest } from "next/server";

export const runtime = "edge";

export async function GET(req: NextRequest) {
  const { searchParams } = new URL(req.url);
  const title = searchParams.get("title") || "XPT Dev Engineering Hub";

  return new ImageResponse(
    (
      <div
        style={{
          height: "100%",
          width: "100%",
          display: "flex",
          flexDirection: "column",
          justifyContent: "space-between",
          backgroundColor: "#0f172a",
          padding: "60px 80px",
          color: "white",
        }}
      >
        <div style={{ fontSize: "28px", fontWeight: "bold", color: "#3b82f6" }}>
          XPT Dev
        </div>
        <div style={{ fontSize: "52px", fontWeight: 800 }}>
          {title}
        </div>
        <div style={{ fontSize: "22px", color: "#94a3b8" }}>
          xptdev.com · Developer Utilities & Architecture
        </div>
      </div>
    ),
    { width: 1200, height: 630 }
  );
}
```

## 3. Core Web Vitals Optimization

### 1) Largest Contentful Paint (LCP < 2.5s)
* **Self-Hosted Web Fonts**: Utilize `next/font` with zero layout shift font swapping.
* **Preloaded Priority Images**: Mark hero banners with `priority` to inject preload `<link>` tags into the initial HTML document payload.

### 2) Interaction to Next Paint (INP < 200ms)
* **Long Task Elimination**: Defer non-critical analytics and heavy script execution using `next/script` with `strategy="lazyOnload"`.
* **RSC Minimization**: Keep large utility bundles on the server side to minimize client hydration overhead.
