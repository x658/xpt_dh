## 一、 PAYG 升级号（Pay As You Go）的核心红利与政策机制

纯免费账号（Free Tier）在甲骨文的调度队列中优先级极低，不仅开机经常遭遇“Out of host capacity（无可用容量）”报错，还会受到严苛的**闲置资源回收政策（Idle Reclamation Policy）**制约（连续 7 天各项指标低于 20% 将被官方强制关机甚至删机）。

目前全球资深玩家的最优解，是将账号主动升级为 **PAYG（Pay As You Go，按量付费模式）**：

### PAYG 账户两大压倒性优势：
1. **彻底豁免闲置回收机制**：
   * 甲骨文官方明确规定：**闲置回收政策仅适用于纯未付费的 Free Tier 账户**。
   * 一旦升级为 PAYG，即使机器处于 0% CPU 负载、数月无访问，**官方也绝不会以闲置为由停机或收回**，彻底告别挂机防关机脚本。
2. **只要锁死配额，账单永远为 \$0.00**：
   * 免费额度是按“核心小时数”计算的：每月拥有 **3000 OCPU 小时 + 18000 GB 内存小时**。
   * 例如你创建一台 **2 核 12G 内存**的实例，整月消耗为 1488 OCPU 小时 + 8928 GB 内存小时，**刚好只占用了免费额度的 50%**，下个月账单依然是稳稳的 \$0.00！

## 二、 避免意外扣费（防反薅）的四大黄金守则 ⚠️

很多用户绑定了外币信用卡，如果不小心触碰了付费资源，次月可能会收到账单。请严格守住以下 4 条底线：

### 1. 引导卷（系统盘）残留陷阱（最常见扣费源头）
* **规则**：整个账号下所有机器的磁盘总容量加起来，**不超过 200 GB 永久免费**。
* **致命陷阱**：在后台删除某台云服务器（Instance）时，甲骨文默认**不会自动删除该机器挂载的系统盘（Boot Volume）**！如果你删了旧机器又开新机器，老磁盘会默默在后台继续计费，累计超过 200GB 就会按月产生存储账单。
* **避坑动作**：删除机器时，**必须勾选“Permanently delete the attached boot volume（永久删除关联的引导卷）”**。

### 2. 闲置公网 IPv4 资源坑
* 每台运行中的实例默认分配 1 个免费的临时公网 IPv4 地址。
* **避坑动作**：切勿在后台申请大量未绑定的“保留公网 IP（Reserved Public IP）”，闲置的保留 IP 可能会被计入资源占用费用。

### 3. 版权与 P2P 滥用防封号
* 出网流量虽然有 10TB 免费额度，但**严禁运行 BT / PT 种子下载**！海外机房对版权（DMCA）极其敏感，一旦收到版权保护机构的侵权投诉信，账号将被直接物理注销。

### 4. 第一天必做：设置 \$1 预算邮件预警（Budget Alert）
在控制台进入 **Governance & Administration** -> **Budgets**，创建一个月度预算为 **\$1** 的规则。设置当实际支出达到 **\$0.01（或 1%）** 时立刻向你的个人邮箱发送报警邮件，确保发生误操作时第一时间能够止损。

## 三、 突破“打不开网页”：解除双重防火墙封锁

甲骨文实例开机后，新手最常遇到的困惑是：“我已经在服务器里启动了 Nginx 或宝塔面板，为什么外网 IP 无法访问？”
这是因为甲骨文设置了**双层安全防护墙**：

### 步骤 1：放行云控制台入站规则（VCN Ingress Rules）
1. 登录甲骨文云后台，进入 **虚拟云网络 (VCN)** -> 选择当前子网 -> 点击 **默认安全列表 (Default Security List)**；
2. 点击 **添加入站规则 (Add Ingress Rules)**；
3. 源 CIDR 填入 `0.0.0.0/0`，IP 协议选择 **所有协议 (All Protocols)**，保存生效。

### 步骤 2：清空系统自带的严格 iptables
Oracle 官方系统镜像内置了极度苛刻的本地防火墙，需要登录 SSH 执行以下命令彻底放行：

```bash
# 1. 允许所有入站、转发与出站数据包
sudo iptables -P INPUT ACCEPT
sudo iptables -P FORWARD ACCEPT
sudo iptables -P OUTPUT ACCEPT

# 2. 清空既有拦截规则
sudo iptables -F

# 3. 持久化保存规则，防止重启系统后复原
sudo netfilter-persistent save
```
