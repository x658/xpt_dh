現代のインディーハッカー（個人開発者）は、フルマネージドのサーバーレスとエッジ技術を活用することで、専任のインフラチームを持たずとも月間数百万リクエストを捌くサービスをほぼゼロコストで立ち上げることができます。

---

## 推奨スタック

1. **フロントエンド**: Next.js 16 (App Router) + next-intl による多言語対応 + Vercel
2. **バックエンド・エッジコンピューティング**: Cloudflare Workers
3. **データベース**: Cloudflare D1 (サーバーレスSQLite) + Drizzle ORM
4. **オブジェクトストレージ**: Cloudflare R2 (下り転送料金無料)
5. **デザイン**: Tailwind CSS + shadcn/ui
