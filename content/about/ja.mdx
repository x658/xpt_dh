# XPT Dev について

**XPT Dev** は、フルスタックエンジニア、個人開発者、およびグローバルプロダクトチームのための技術プラットフォームです。**実践主義、オープンソース精神、ゼロナレッジプライバシー**の3大原則に基づき、安全で高速なブラウザ内開発ツールと、本番運用に直結する深層技術ガイドを提供しています。

---

## 🎯 ミッションと開発理念

現代のオンラインツールや技術ブログの中には、過剰な追跡トラッカーや不透明なデータ収集、AI による質の低い記事が多く見受けられます。XPT Dev は、エンジニアが真に信頼できる生産性の高い環境を提供するために設立されました：

1. **ゼロナレッジ・クライアントサイド・プライバシー（Zero-Knowledge Privacy）**：
   コードスニペット、JWT トークン、API キーなどの機密データを外部サーバーに送信することはありません。すべてのフォーマット、デコード、ハッシュ計算は、ブラウザ標準の **Web Cryptography API** を使用して端末のローカル環境で安全に実行されます。
2. **本番対応の実践的アーキテクチャ（Production-Ready Architecture）**：
   紹介するすべての技術ガイド（Docker オーケストレーション、PostgreSQL 最適化、Cloudflare D1 エッジ設計など）は、実際の商用システムにおける運用ノウハウに基づいています。
3. **オープンスタンダードと多言語展開（Global & Open Standards）**：
   日本語、英語、中国語のネイティブ対応を行い、すべてのコアテンプレートは商用利用可能な MIT ライセンスの下で公開されています。

## 🛡️ 記事の品質管理と編集基準 (Editorial Standards)

信頼性の高い技術情報をお届けするため、厳格なレビュー基準を設けています：

* **コード再現性の保証**：掲載されているすべてのコマンド、Docker Compose 設定、TypeScript コードは、クリーンな本番環境で動作検証済みです。
* **セキュリティ最優先**：OWASP のセキュリティ基準に準拠し、潜在的な脆弱性やレート制限対策を明示しています。
* **継続的な情報更新**：Web 標準やクラウド API の変更に合わせて、過去記事の検証とアップデートを定期的に実施しています。

## ☁️ インフラストラクチャと採用技術
