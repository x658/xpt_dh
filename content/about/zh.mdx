# 关于 XPT Dev

**XPT Dev** 是一个专注于极客精神与实用主义的开发者平台，致力于为全球工程师与独立开发者提供轻量、安全、完全免费的在线提效工具与实战技术指南。

---

## 🚀 核心生态

* **[在线开发工具箱](https://tools.xptdev.com)**：集合了 100+ 款纯前端计算的开发利器，包括 JSON 格式化、JWT 解析、哈希计算、Base64 编解码等，数据 100% 本地运算，绝不上云泄密。
* **[XPT 专属域名邮箱](https://mail.xptdev.com)**：基于 Serverless 架构的高可用私有域名邮件服务。
* **[技术博客](/zh/blog)**：精选前沿 Web 开发技术、云原生部署方案与全栈实战教程。

---

## 🔒 隐私第一理念

我们深知代码与凭证的敏感性。XPT Dev 工具箱所有加密与解析功能均基于现代浏览器的 Web API 本地计算，拒绝任何形式的数据上传与偷跑。
