# 隐私政策

欢迎访问 **XPT Dev**（`https://xptdev.com`）。保护访问者与开发者社区的数据隐私和安全是我们的核心工程原则。本《隐私政策》旨在透明、详细地说明 XPT Dev 收集哪些信息、如何使用这些信息，以及我们在客户端工具与广告合规方面的隐私保护机制。

如对本隐私政策有任何疑问，请随时通过 **admin@xptdev.com** 与我们联系。

---

## 1. 零知识客户端开发者工具（数据本地处理承诺）

XPT Dev 提供一系列在线开发者实用工具（`/tools`），包括 JSON 格式化与 RFC 8259 校验、Base64/URL 编解码、UUID v4 生成、SHA-256/SHA-512 哈希摘要计算、Unix 时间戳转换以及高熵随机密钥生成器。

* **100% 浏览器本地沙箱执行**：您在上述工具中输入的任何文本、JSON 载荷、API 凭证、代码片段或加密字符串，均完全通过您浏览器内置的原生 **Web Cryptography API** 和本地 JavaScript 引擎在客户端内存中完成计算。
* **绝不上传或留存**：XPT Dev **绝不会**向任何远程服务器发送、记录、存储或分析您在工具箱中输入的数据。当您关闭或刷新网页标签页时，所有临时计算数据即从本地内存中彻底清除。

## 2. 我们收集的信息类型

### 2.1 您主动提供的信息
当您主动订阅我们的技术工程周刊（Newsletter）或通过电子邮件（`admin@xptdev.com`）联系我们时，我们可能会收集：
* 您的电子邮箱地址（仅用于发送技术更新或回复您的咨询）。
* 您在邮件或表单中主动填写的反馈内容。

您可以随时点击邮件底部的“退订（Unsubscribe）”链接取消订阅。

### 2.2 标准访问日志与分析数据
与所有标准 Web 服务及边缘计算网络（Vercel 与 Cloudflare）一致，XPT Dev 会在访问过程中记录基础的匿名访问日志。日志信息包括但不限于：
* 互联网协议（IP）地址（按合规要求进行匿名化处理）
* 浏览器类型与操作系统版本
* 访问日期、时间戳以及引荐来源页面（Referrer）
* 页面加载性能指标（Core Web Vitals）

这些信息不与任何个人身份信息挂钩，仅用于保障边缘节点安全、防御恶意 DDoS 攻击、统计整体访问趋势以及优化网站性能。

## 3. Cookie 政策与 Google AdSense 广告披露声明

### 3.1 必要与偏好 Cookie
XPT Dev 使用必要的 Cookie 和浏览器本地存储（`localStorage`）来保存您的界面偏好设置，例如您选择的语言版本（中文 `zh`、英文 `en`、日文 `ja`）以及深色/浅色主题模式（Dark/Light Mode）。

### 3.2 Google AdSense 与 DoubleClick DART Cookie 声明
为了维持免费开发者工具与深度技术文档的服务器运营，我们在 `https://xptdev.com` 上使用 **Google AdSense** 展示广告。根据 Google AdSense 计划政策，我们在此明确披露：
* **包括 Google 在内的第三方供应商会使用 Cookie，根据用户之前对本网站或互联网上其他网站的访问记录来投放广告。**
* **Google 使用广告 Cookie（包括 DoubleClick DART Cookie），使其及其合作伙伴能够根据用户对 `https://xptdev.com` 及互联网上其他站点的访问情况向用户展示相关广告。**
* **如何退订个性化广告**：用户可以随时访问 **[Google 广告设置（Google Ads Settings）](https://adssettings.google.com/)**（`https://www.google.com/settings/ads`）选择停用个性化广告。此外，您也可以访问 **[www.aboutads.info/choices](https://www.aboutads.info/choices/)** 停用第三方供应商将 Cookie 用于个性化广告。

如需进一步了解 Google 如何在合作伙伴网站上处理数据，请参阅 Google 官方隐私说明：[Google 如何使用来自应用或网站的信息](https://policies.google.com/technologies/partner-sites?hl=zh-CN)。

## 4. 第三方网站与隐私政策说明

XPT Dev 的技术文章中可能包含指向第三方开源仓库（如 GitHub）或官方文档的外部链接。本《隐私政策》不适用于外部网站或第三方广告商。我们建议您在访问外部站点时查阅其各自的隐私政策。

您也可以通过浏览器设置自行选择禁用或管理特定网站的 Cookie。

## 5. 您的数据保护权利（GDPR 与 CCPA 合规）

无论您身处何地，我们尊重并保障您的数据权利：
* **访问、更正与删除权**：您有权要求查看、更正或彻底删除我们持有的与您相关的个人信息（如邮件订阅记录）。
* **限制处理与反对权**：您有权随时撤回同意或反对特定数据处理行为。
* **不出售个人数据承诺**：XPT Dev 绝不向任何第三方出售、交易或出租用户的个人信息。

如需行使上述任何权利，请发送邮件至 **admin@xptdev.com**，我们将在合理期限内及时处理。

## 6. 未成年人隐私保护

我们高度重视对未成年人网络安全的保护。XPT Dev 不会故意收集 13 周岁以下儿童的任何个人身份信息。如果您发现未成年人在未经监护人同意的情况下向本站提供了个人信息，请立即联系我们（**admin@xptdev.com**），我们将第一时间予以彻底删除。
