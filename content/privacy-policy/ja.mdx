# プライバシーポリシー

**XPT Dev**（`https://xptdev.com`）は、訪問者および開発者コミュニティの皆様のプライバシーとセキュリティ保護を最優先事項としています。本プライバシーポリシーでは、XPT Dev が収集する情報の種類、その利用方法、およびクライアントサイド・ツールのセキュリティと広告配信に関する方針について詳しく説明します。

本ポリシーに関するご質問や詳細については、**admin@xptdev.com** までお気軽にお問い合わせください。

---

## 1. ゼロ知識クライアントサイド開発ツール（ローカル処理の保証）

XPT Dev が提供する開発者向けオンラインユーティリティ（`/tools`：JSON 整形・検証、Base64/URL エンコード、UUID v4 生成、SHA-256/SHA-512 ハッシュ算出、Unix タイムスタンプ変換、高強度シークレット生成など）は、以下のプライバシー設計に基づいています：

* **100% ブラウザ内ローカル実行**：ツールに入力されたすべての文字列、JSON データ、API トークン、暗号鍵、コードスニペットは、お使いのブラウザ標準の **Web Cryptography API** およびローカル JavaScript エンジンによって端末内のメモリ上でのみ処理されます。
* **サーバーへの送信・保存なし**：XPT Dev が入力データを外部サーバーへ送信、記録、保存、または閲覧することは**一切ありません**。ブラウザのタブを閉じるか再読み込みすると、データはメモリから完全に消去されます。

## 2. 収集する情報について

### 2.1 お客様から任意でご提供いただく情報
ニュースレターへの登録やメール（`admin@xptdev.com`）でのお問い合わせの際に、以下の情報を収集する場合があります：
* メールアドレス（ニュースレターの配信またはお問い合わせへの回答のため）
* お問い合わせ内容やフィードバック本文

ニュースレターは、各メール内の配信停止リンク（Unsubscribe）からいつでも解除できます。

### 2.2 アクセスログと解析データ
標準的な Web サーバーおよびエッジネットワーク（Vercel および Cloudflare）と同様に、XPT Dev では以下の標準的なログ情報を記録します：
* IP アドレス（適切に匿名化処理されたもの）
* ブラウザの種類とバージョン、OS 環境
* アクセス日時、参照元ページ（リファラ）
* パフォーマンス指標（Core Web Vitals）

これらの情報は個人を特定するものではなく、不正アクセスの防止、エッジセキュリティの維持、およびサイトのパフォーマンス改善のためにのみ利用されます。

## 3. Cookie の使用および Google AdSense 広告に関する開示

### 3.1 必須 Cookie とローカルストレージ
XPT Dev は、選択された表示言語（`ja`、`en`、`zh`）やテーマ設定（ダークモード／ライトモード）などのユーザー設定を保持するために、Cookie およびブラウザの `localStorage` を使用します。

### 3.2 Google AdSense および DoubleClick DART Cookie について
当サイト（`https://xptdev.com`）では、無料の開発者ツールおよび技術ドキュメントの運営・維持のために、第三者配信の広告サービス **Google AdSense** を利用しています。Google AdSense プログラムポリシーに基づき、以下の事項を開示いたします：
* **Google を含む第三者配信事業者は、Cookie を使用して、ユーザーが当サイトや他のウェブサイトに過去にアクセスした際の情報に基づいて広告を配信します。**
* **Google が広告 Cookie（DoubleClick DART Cookie を含む）を使用することにより、ユーザーが当サイトや他のサイトにアクセスした際の情報に基づいて、Google やそのパートナーが適切な広告をユーザーに表示できます。**
* **パーソナライズド広告の無効化（オプトアウト）**：ユーザーは、**[Google の広告設定（Google Ads Settings）](https://adssettings.google.com/)**（`https://www.google.com/settings/ads`）にアクセスして、パーソナライズド広告をいつでも無効にできます。また、**[www.aboutads.info/choices](https://www.aboutads.info/choices/)** にアクセスして、第三者配信事業者がパーソナライズド広告のために Cookie を使用することを無効にすることも可能です。

Google のサービスを使用するサイトやアプリから収集した情報の Google による使用については、[Google のポリシーと規約ページ](https://policies.google.com/technologies/partner-sites?hl=ja)をご参照ください。

## 4. 外部リンクと第三者のプライバシーポリシー

当サイトの技術記事には、GitHub リポジトリや公式ドキュメントなどの外部サイトへのリンクが含まれる場合があります。本プライバシーポリシーは外部サイトには適用されませんので、移動先のサイトのプライバシーポリシーをご確認ください。

なお、ブラウザの設定により Cookie の受け入れを拒否・無効化することも可能です。

これらの権利を行使される場合は、**admin@xptdev.com** までご連絡ください。
